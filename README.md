## 🚀 How to Upload & Deploy

### Method 1: Push to GitHub & Deploy on Vercel
In your terminal inside this folder:
```bash
git init
git add .
git commit -m "Initial portfolio commit"
git branch -M main
git remote add origin https://github.com/Lunar-Dev17/<your-repo-name>.git
git push -u origin main
```
Then log in to [vercel.com](https://vercel.com), click **Add New Project**, import the GitHub repo, and hit **Deploy**.

### Method 2: Drag & Drop to Netlify (Instant)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop this `Portfolio` folder.
3. Your site is live in seconds.
